# Phase 4 — UI Design Contract

> Visual and interaction contract for the Real Inspection Pipeline phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** Phase 5 owns full PRD Minimalist Light polish (DSGN-01–04, CAM-04/05/06). Phase 4 documents **interaction contracts and minimal styling for new/changed UI only** — reuse existing Tailwind patterns from `src/components/`.

| Property | Value |
|----------|-------|
| Tool | none |

## Spacing Scale

Declared values (multiples of 4). Reuse existing Tailwind utility classes — do not introduce new spacing tokens in Phase 4.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), inline badge padding |
| sm | 8px | Compact gaps (`gap-2`), tier quick-select grid |
| md | 16px | Default horizontal padding (`px-4`), section gaps (`gap-3`) |
| lg | 24px | Drawer top padding, magnifier offset margin |
| xl | 32px | Bottom safe-area padding (`pb-8`) |
| 2xl | 48px | Primary action button height (`h-12`), touch targets |
| 3xl | 64px | Sticky header height reference (~61px top offset for filter bar) |

Exceptions: **80px** magnifier lens diameter (`w-20 h-20`); **94px** magnifier vertical offset above active divider (`-top-[94px]`) — ROI-04 precision affordance, not layout rhythm.

|------|------|--------|-------------|

## Phase 4 Interaction Contracts

### 1. First-Baseline Capture Flow (ROI-01, D-01–D-05)

| Trigger | Behavior | Visual |
|---------|----------|--------|
| Shutter on shelf with `hasPersistedBaseline === false` | Capture frame → set pending baseline → route **directly** to `ROI_CONFIG` | **No** `ScanningAnimationOverlay`; no diff |
| `RoiSetupView` background | **Just-captured frame** (`pendingBaselineImageUrl`), not demo CDN | Same stage layout as existing calibration view |
| Header subtitle (first baseline) | Show first-baseline hint copy (see Copywriting) | Replace or supplement `tierSubtitle` when `isFirstBaseline === true` |
| **重拍 Retake** (ROI-05) | Discard pending capture; return to `CAMERA_IDLE` | Third button in bottom row — `t.retake`, `rounded-full h-12`, secondary style matching reset button |
| **确认并保存基准** | Persist JPEG Blob + splits + dimensions → `hasPersistedBaseline = true` → `CAMERA_IDLE` | Existing save animation (1.5s green flash on button) |
| Manual ROI re-entry | Existing baseline image as background; recalibrate dividers only | Unchanged from Phase 3 |

### 2. ROI Divider + Magnifier (ROI-02–ROI-04)

| Element | Contract |
|---------|----------|
| Dividers | 4 horizontal lines at `splitYPercentages`; pointer drag with 5% min gap between neighbors |
| Inactive beam | `h-0.5 bg-[#4EDEA3]` dashed glow |
| Active beam | `h-1 bg-[#10B981]` with shadow glow |
| Handles | Left tier pill + right coordinate pill (`Y: {n}%`) with `ChevronsUpDown`; `cursor-ns-resize` |
| Magnifier | **80px** circle (`w-20 h-20`), **2×** zoom, positioned **~94px above** active divider center; crosshair overlay; labels `2.0X ZOOM` + `edgeSnapped` |
| Touch | `touch-none` on stage; pointer capture on drag |
| Bottom tier quick-select | 4-column grid — tap selects active tier for magnifier focus |

### 3. Inspection Scan + Worker (VIS-04, TECH-06, STAB-03)

| State | Duration | Visual |
|-------|----------|--------|
| `SCANNING_ANIM` | 0–800ms | Frozen capture frame + cyan scan beam top→bottom (`animate-scan-beam 0.8s`); shutter flash overlay; bottom pill **正在进行透视配准与差分分析...** |
| `PROCESSING` | Until worker returns | Same frozen frame + pulsing dark overlay; `Loader2` spinner; bottom pill **正在分析展架差异，请稍候...** |
| Worker complete | — | Transition to `RESULT_INSPECT` regardless of whether PROCESSING was shown |
| Shutter lock | Entire capture→result path | Existing `isShutterLocked` — ignore repeat taps |

Worker runs **concurrently** with scan animation; UI thread must not block.

### 4. Result Inspect — Anomaly Overlay (RSLT-01, VIS-02)

| Element | Contract |
|---------|----------|
| Image | Full-width `aspect-[9/16]` capture photo as base layer |
| MISSING box | `border-2 border-[#EF4444] bg-[#EF4444]/15 rounded-xl`; pulsing `+` icon inside; floating badge with confidence |
| MOVED box | `border-2 border-[#F59E0B] bg-[#F59E0B]/15 rounded-xl`; `« title »` displacement label |
| Coordinates | Normalized `boundingBox` (0–1) mapped to `%` top/left/width/height |
| Max boxes | Cap 8 per tier (D-09) — no UI change when capped; fewer boxes rendered |
| Layer toggle | Existing `Layers` button hides/shows all boxes |

### 5. Long-Press Blink Compare (RSLT-02)

| Gesture | Behavior |
|---------|----------|
| `mousedown` / `touchstart` on viewport | Hide AR boxes; swap image to baseline; show **基准标准图** overlay chip |
| `mouseup` / `touchend` / `mouseleave` / `touchcancel` | Restore capture image + boxes |
| Hint badge | Bottom-center **长按对比基准原图** — scales down slightly while active |

### 6. Tap-to-Dismiss (RSLT-03)

| Gesture | Behavior |
|---------|----------|
| Tap anomaly box or badge `X` | 220ms shrink/fade (`animatingDismissIds`) → `dismissed: true` on anomaly |
| Stat capsule | `missingCount` / `displacedCount` decrement immediately |
| Compliance | Recalculate from remaining active anomalies (existing formula) |

### 7. Stat Capsule Filter (RSLT-04)

| Chip | Zero count | Active filter | Inactive |
|------|------------|---------------|----------|
| Missing | `bg-slate-100 text-slate-500` + **无缺失** | `bg-[#EF4444] text-white ring-2 ring-red-400` | `bg-red-50 text-[#EF4444] border border-red-200` |
| Displaced | same pattern | `bg-[#F59E0B] text-white ring-2 ring-amber-400` | `bg-amber-50 text-[#D97706] border border-amber-200` |
| Toggle | Tap active chip → reset to `ALL` | Tap inactive → filter to that type only | Non-matching boxes hidden from viewport |

Sticky position: `top-[61px]` below header.

### 8. Continuous Tolerance Slider (RSLT-05, VIS-03, D-11–D-14) — **NEW UI**

Replace the existing 3-button strict/normal/loose grid with:

| Property | Value |
|----------|-------|
| Control | Native `<input type="range" min="0" max="100" step="1">` styled to match drawer |
| Track | `h-2 rounded-full bg-slate-200`; fill via linear-gradient or pseudo-element in `#006C49` |
| Thumb | `w-5 h-5 rounded-full bg-[#006C49] shadow-md border-2 border-white` — **44px min touch target** via invisible padding |
| Value display | `font-mono-numbers text-xs font-bold text-[#006C49] bg-emerald-100/80 px-2 py-0.5 rounded-full` showing `{n}` |
| Preset ticks | Visual markers at **25, 50, 75** with labels **严格/标准/宽松** (CN) or **Strict/Normal/Loose** (EN) below track |
| Debounce | **150ms** before re-invoking worker diff |
| Loading feedback | While re-diff in flight: subtle opacity on stat counts or disable slider thumb — do not block viewport |
| Panel container | Existing `bg-slate-50 p-3 rounded-xl border border-slate-200/60` with `Sliders` icon + `toleranceSensitivity` label |

Slider change triggers **full worker re-diff** on current capture + baseline — not client-side filter.

### 9. Complete Inspection (RSLT-06)

| Action | Behavior |
|--------|----------|
| **确认并完成巡检** tap | Confetti burst (existing) → save `AuditRecord` with anomalies including `dismissed` flags → return to **current shelf** `CAMERA_IDLE` |
| Back arrow | Same return without saving audit (existing `onBackToCamera`) |

## UI Considerations

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | result-anomaly-list (list-collection) | ✅ covered | Zero active anomalies: stat chips show documented noMissing/noDisplaced copy; viewport shows capture with no boxes |
| empty | roi-tier-grid (list-collection) | ✅ covered | Always 4 tiers populated from DEFAULT_SPLIT_Y or saved splits — no empty tier state |
| loading | scan-overlay (media) | ✅ covered | SCANNING_ANIM 800ms beam + PROCESSING spinner until worker returns — existing ScanningAnimationOverlay variants |
| loading | tolerance-slider (interactive-control) | ✅ covered | 150ms debounce then worker re-diff; slider remains interactive; counts update on result |
| error | vision-worker (media) | ✅ covered | Worker failure shows documented analysis-failed copy; user returns to camera to retry capture |
| error | baseline-save (form) | ✅ covered | QuotaExceededError surfaces existing quotaExceededTitle/quotaExceededGuide banner (Phase 2 pattern) |
| populated | result-anomaly-list (list-collection) | ✅ covered | 1–32 boxes max (8/tier × 4); red/yellow boxes with badges per RSLT-01 contract |
| populated | roi-calibration-stage (media) | ✅ covered | Captured or baseline image fills stage; 4 dividers + magnifier on active tier |
| partial | audit-record-save (form) | ✅ covered | Dismissed anomalies persist with dismissed:true in saved AuditRecord (D-23) |
| overflow | stat-capsule-bar (nav) | ✅ covered | horizontal scroll with no-scrollbar when chips exceed width — existing overflow-x-auto |
| overflow | tier-quick-select (list-collection) | ✅ covered | Tier title truncates with truncate class in 4-col grid |
| zero-one-many | anomaly-filter-chips (list-collection) | ✅ covered | Copy switches: noMissing/noDisplaced at 0; count + label at 1+; plural via existing I18N units |
| zero-one-many | tolerance-preset-ticks (static-content) | ✅ covered | Three tick labels always visible at 25/50/75 regardless of slider position |
| long-text | anomaly-badge-title (static-content) | 🧪 backstop | Product titles inside boxes use text-[9px] with truncate; held-out visual test for 40+ char titles |

| populated | first-baseline-flow (nav) | ✅ covered | Shutter intercept routes to ROI_CONFIG with pending capture — no scan animation (D-01) |
| populated | blink-compare (interactive-control) | ✅ covered | Long-press swaps baseline image, hides boxes, shows goldenBaseline chip |
| populated | tap-dismiss (interactive-control) | ✅ covered | 220ms animation then decrement stat capsule counts |
| loading | opencv-worker-init (interactive-control) | ⚠ unresolved | First worker OpenCV WASM load may exceed 800ms on slow devices — planner assumes PROCESSING overlay covers; no separate init UI |
