<objective>
Two fixes the user asked for (Chinese, verbatim in the task description):
(1) hand-held re-shoots are slightly deformed, so align locally after the global match before diffing;
(2) an item added in the later photo is wrongly reported as missing. It must show as "added".

Decision IDs below refer to the orchestrator's locked design, numbered in order:
- D-01: `'ADDED'` joins `DetectedAnomaly['type']`; worker title `'Added'`.
- D-02: symmetric classification. Vanished texture/contrast (today's ratio/delta thresholds) gives MISSING. Appeared gives ADDED. Both or neither gives MOVED. The brightness-polarity rules (void delta, foreground means, centroid displacement) are dropped. The production-unused MISSING-over-MOVED dedupe helper is deleted.
- D-03: move pairing after classification (area <= 2x, RGB distance < 35, centre distance <= 4x the larger size), relabelling the pair MOVED.
- D-04: counts. `addedCount`; actual = standard - missing + added; -2 compliance per added. `InspectionAnalysisResult.addedCount` is required. `AuditRecord`/`PersistedAuditRecord.addedCount` are optional (old records load as 0).
- D-05: result page. Third chip, sg-scan colour for ADDED, localized label + confidence badges for ADDED and MOVED, cn/en i18n. AuditHistoryModal shows an added column.
- D-06: tests. Permanent added-items + move-pair worker test; classifier/pairing/stats/view tests; every existing assertion unchanged.
- D-07: `refineLocalAlignment`. Farneback flow on a downscaled pair, heavily smoothed and clamped, applied with `cv.remap` to aligned gray, every colour plane and `valid`. Skipped on identity. Follows the WASM-view rule. Bbox mapping ignores the small residual.
- D-08: acceptance. Parallax regression test (0 at >= 0.85; totals < 4 and < 11), all suites + deep sweeps green, <= ~300 ms added, tsc clean. Otherwise D-07 is not shipped and the trade-off is reported.

Purpose: `classifyContourType` has no "added" outcome, and its first rule assumes a dark shelf back, so added items read as MISSING (light back) or MOVED (dark back). Depth parallax from a hand-held re-shoot leaves residual motion that one homography cannot remove, giving up to 3 confident false alarms per 8 scenes at 3%/6%.

Output: symmetric classifier + pairing, added counts end-to-end (worker, stats, UI, persistence), a local alignment refinement step, and permanent regression tests for both.
</objective>
