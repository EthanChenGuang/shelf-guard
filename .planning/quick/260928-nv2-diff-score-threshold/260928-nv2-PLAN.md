<objective>
Give every detected difference a real, calibrated confidence percentage and only show and count
differences at or above an adjustable confidence threshold (default 85%), per the user's request
("only differences confirmed at e.g. 85% or more should be shown; currently ~30% differences are shown").

Decision IDs below refer to the orchestrator's locked design, numbered in order:
D-01 confidence module + formula, D-02 worker score/confidence, D-03 threshold-aware stats,
D-04 App state/persistence/derived counts/audit filtering, D-05 result-page filter + slider + i18n,
D-06 tests and green suite. The formula and the 85 default are locked — do not retune them.

Purpose: The result page is currently too noisy because `score` is an area-size measure, not a
confidence, and nothing filters on it. Replacing it with a calibrated confidence plus a threshold
removes shadow/glare/parallax noise (median ~41%) while keeping removed products (~100%) and clearly
visible moves (~90%+).

Output: new `src/lib/vision/confidence.ts`; worker emits confidence; stats, result page and App honor
a persisted `minConfidence`; tests for each layer.
</objective>
